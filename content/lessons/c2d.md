## Point

**モル濃度**は、溶液 1 L 中に含まれる**溶質**の物質量（mol）である。
VI: Nồng độ mol (**モル濃度**) cho biết 1 L dung dịch chứa bao nhiêu mol chất tan (**溶質**).

\[ C = \frac{n}{V} \quad\Leftrightarrow\quad n = C \times V \]

\(V\) の単位は L。mL で与えられたら L に直す（500 mL = 0.500 L）。
VI: \(V\) tính bằng lít. Đề Nhật hay cho mL, nhớ đổi: 500 mL = 0.500 L.

## 例題

水酸化ナトリウム \(\ce{NaOH}\) 0.20 mol を水に溶かして 500 mL にした。モル濃度は何 mol/L か。
VI: Hòa tan 0.20 mol NaOH thành 500 mL dung dịch. Nồng độ mol là bao nhiêu?
解答: \(C = 0.20 \div 0.500 = 0.40\) mol/L

## 練習

### 問1
0.20 mol/L の塩化ナトリウム \(\ce{NaCl}\) 水溶液 500 mL に含まれる NaCl は何 g か。（Na = 23, Cl = 35.5）
VI: 500 mL dung dịch NaCl 0.20 mol/L chứa bao nhiêu gam NaCl?
1. 117
2. 58.5
3. 29.3
4. 11.7
5. 5.85 ✓
6. 2.93
解説: 500 mL = 0.500 L。\(n = 0.20 \times 0.500 = 0.10\) mol、\(M = 23 + 35.5 = 58.5\) g/mol より \(m = 0.10 \times 58.5 = 5.85\) g。正解は⑤。
VI: Đổi 500 mL = 0.500 L. \(n = 0.20 \times 0.500 = 0.10\) mol; \(M = 23 + 35.5 = 58.5\) g/mol nên \(m = 0.10 \times 58.5 = 5.85\) g. Đáp án ⑤.

## まとめ

- \(C = n \div V\)（\(V\) は L）
VI: \(C = n \div V\), \(V\) tính bằng L.
- mL は L に直してから計算する。
VI: Đổi mL sang L trước khi tính.
